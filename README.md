# 🏢 Tanakrit Dormitory — หอพักชายธนกฤษฎ์ นครศรีธรรมราช (v1.0.3)
> **ระบบบริหารจัดการหอพักแบบ All-in-One ครบวงจร (Modern Dormitory Management System)**  
> **Version 1.0.3** — เชื่อมต่อระบบฐานข้อมูลสด Supabase Cloud เต็มรูปแบบ พร้อมระบบแนบสลิป, จองห้องพักออนไลน์, และจัดการผู้ใช้งาน

ระบบเว็บไซต์ประชาสัมพันธ์และโปรแกรมบริหารจัดการหอพักชายธนกฤษฎ์ จังหวัดนครศรีธรรมราช ออกแบบด้วยธีมสี Deep Teal, Emerald, Sand, และ Mint สวยงาม ทันสมัย รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ ทำงานแบบ Standalone และเชื่อมต่อฐานข้อมูลคลาวด์แบบ Real-time (เปิดใช้งานได้ทันทีทั้งผ่านเบราว์เซอร์ `file:///`, เว็บเซิร์ฟเวอร์ และ GitHub Pages)

## 🚀 มีอะไรใหม่ในเวอร์ชัน v1.0.3 (Changelog & What's New)

### 1. ☁️ เชื่อมต่อฐานข้อมูลสด Supabase Cloud เต็มรูปแบบ (Live Database Integration)
* ย้ายจากฐานข้อมูล LocalStorage จำลอง มาเชื่อมต่อกับ **Supabase Cloud (PostgREST API)** แบบเรียลไทม์ 100%
* ข้อมูลทั้งหมดถูกซิงค์สดระหว่างทุกอุปกรณ์และผู้ใช้งาน
* ครอบคลุม 9 ตารางข้อมูลหลัก: `rooms`, `tenants`, `bookings`, `requests`, `meter_readings`, `maintenance`, `parcels`, `announcements`, `settings`, และ `users`

### 2. 👤 ระบบจัดการบัญชีผู้ใช้งาน (User Management & Live Authentication)
* **Live Authentication:** ระบบล็อกอินตรวจสอบข้อมูลสดจากตาราง `users` ใน Supabase พร้อมระบบสำรอง Dual-Persistence จดจำรหัสผ่านที่เปลี่ยนใหม่ได้ทันทีแม้ในสถานะออฟไลน์
* **Password Update System:** รองรับการเปลี่ยนรหัสผ่านในหน้า "ตั้งค่าระบบและบัญชีผู้ใช้งาน" มีผลต่อการล็อกอินทันทีทั้งบน Cloud และ Local Session Storage
* **Admin User Management:** เมนูใหม่สำหรับผู้ดูแลระบบ จัดการรายชื่อผู้ใช้, เพิ่ม/แก้ไขข้อมูล, กำหนดระดับสิทธิ์ (Admin / Staff / Student), รีเซ็ตรหัสผ่าน, และสลับสถานะระงับ/เปิดใช้งานบัญชี (Active/Suspended)
* **Auto-Create Tenant Account:** เมื่อเจ้าหน้าที่ลงทะเบียนผู้พักอาศัยใหม่ ระบบจะสร้างบัญชีผู้ใช้สำหรับล็อกอินให้อัตโนมัติทันที (Username = รหัสนักศึกษา/เบอร์โทร, Password = เลขห้องพัก)

### 3. 💳 ระบบแนบสลิปโอนเงิน & ตรวจสอบการชำระ (Payment Slip Upload & Verification)
* **ฝั่งผู้พักอาศัย:** สแกนจ่ายผ่าน Thai QR PromptPay แล้วสามารถแนบรูปถ่ายสลิปโอนเงินได้โดยตรงในใบแจ้งหนี้ พร้อมระบุหมายเหตุเวลา/ธนาคารที่โอน
* **Client-Side Image Compression:** มีระบบย่อและบีบอัดขนาดรูปภาพอัตโนมัติก่อนอัปโหลด ทำให้โหลดได้รวดเร็วและประหยัดพื้นที่จัดเก็บ
* **สถานะบิลแบบเรียลไทม์:** รอชำระ (`pending`) $\rightarrow$ ⏳ รอตรวจสลิป (`verifying`) $\rightarrow$ ✓ ชำระแล้ว (`paid`)
* **ฝั่งผู้ดูแล/เจ้าหน้าที่:** มีแท็บกรอง "รอตรวจสลิป ⏳", สามารถคลิกดูรูปสลิปขยายใหญ่เต็มหน้าจอ และกดปุ่ม **"อนุมัติการชำระเงิน"** หรือ **"ปฏิเสธสลิป / แจ้งโอนใหม่"** พร้อมระบุเหตุผลได้ทันที

### 4. 📝 ระบบจองห้องพักออนไลน์จากหน้าแรก (Public Room Booking)
* บุคคลภายนอกและผู้สนใจเช่าสามารถกดปุ่ม **"สนใจจองห้องพักออนไลน์"** บนหน้า Landing Page ได้ทันทีโดยไม่ต้องเข้าสู่ระบบ
* ระบุประเภทห้องพัก (Standard Fan, Standard Air, Deluxe Corner), ชั้นที่ต้องการ, วันที่ต้องการย้ายเข้า, และข้อมูลติดต่อ
* บันทึกคำขอลงตาราง `bookings` ใน Supabase และมีหน้าจอ Dashboard สำหรับเจ้าหน้าที่ในการติดตามสถานะ (`pending`, `contacted`, `confirmed`, `cancelled`) พร้อมโทรติดต่อกลับได้ใน 1 คลิก

### 5. 📸 ระบบแนบรูปถ่ายจุดชำรุดในงานแจ้งซ่อม (Maintenance Photo Attachment)
* ผู้พักอาศัยสามารถถ่ายภาพหรือแนบรูปภาพอุปกรณ์ที่ชำรุดเสียหายขณะเปิดใบแจ้งซ่อม
* เจ้าหน้าที่และช่างสามารถคลิกดูรูปถ่ายขยายใหญ่เพื่อประเมินหน้างานและเตรียมอุปกรณ์ซ่อมบำรุงล่วงหน้าได้อย่างแม่นยำ

### 6. 🛠️ การปรับปรุงสถาปัตยกรรมและโครงสร้างโปรเจกต์
* เพิ่มสคริปต์ PowerShell `build_bundle.ps1` สำหรับรวมสคริปต์ JavaScript ในระบบ Windows ได้สะดวก
* ปรับปรุงระบบ Modal สากล และฟังก์ชันดูรูปภาพขยายใหญ่ (Full-screen Image Lightbox)
* ลบไฟล์ที่ซ้ำซ้อน จัดระเบียบโมดูลให้เป็นสัดส่วน และรองรับการทำงานทั้งบน Web Browser โดยตรงและ GitHub Pages

## ✨ ฟังก์ชันและระบบภายใน

### 1. หน้าหลักสำหรับผู้สนใจเช่า (Landing Page)
- **Hero & Overview**: สรุปข้อมูลสำคัญและจุดเด่นของหอพัก (ทั้งหมด 17 ห้อง ใน 3 อาคาร)
- **Online Booking**: ระบบลงชื่อจองห้องพักออนไลน์แบบเรียลไทม์ พร้อมเลือกอาคารที่สนใจ
- **Room Catalog (3 อาคาร)**:
  1. **อาคาร Tanakrit (9 ห้อง)**: ห้องพัดลม ขนาดกว้าง 3.5 M × ยาว 8 M (28 ตร.ม.) ราคา 1,500 ฿/เดือน (เตียง+ที่นอน, ตู้เสื้อผ้า, ห้องน้ำในตัว, ราวตากผ้าหลังห้อง)
  2. **อาคาร KingPhetch (5 ห้อง)**: ห้องพัดลม ขนาดกว้าง 3.5 M × ยาว 8 M (28 ตร.ม.) ราคา 1,500 ฿/เดือน (เตียง+ที่นอน, ตู้เสื้อผ้า, ห้องน้ำในตัว, ราวตากผ้าหลังห้อง)
  3. **อาคาร UnderGround (3 ห้อง)**: ห้องพัดลม ขนาดกว้าง 3 M × ยาว 4 M (12 ตร.ม.) ราคา 800 ฿/เดือน (เตียง+ที่นอน, ตู้เสื้อผ้า, ห้องน้ำรวม)
- **Rate Calculator**: เครื่องคำนวณประมาณการค่าใช้จ่ายแรกเข้าแบบเรียลไทม์
- **Facilities & Location**: สิ่งอำนวยความสะดวกครบครัน (ตู้ซักผ้าหยอดเหรียญ, ตู้กดน้ำหยอดเหรียญ, ศาลาส่วนกลาง, ที่จอดรถมอเตอร์ไซค์+รถยนต์, ฟรี Wi-Fi)

### 2. ระบบบริหารจัดการหลังบ้าน (Management Dashboard)
- **ผังห้องพัก (Interactive Floor Plan — 3 อาคาร)**: แสดงสถานะห้องพัก 17 ห้อง แยกตามอาคาร Tanakrit, KingPhetch, UnderGround
- **ทะเบียนผู้พักอาศัย (Tenants)**: บันทึกข้อมูลสัญญา วันที่เข้าพัก ข้อมูลติดต่อ พร้อมสร้าง User ให้อัตโนมัติ
- **การจองห้องพัก (Bookings)**: ตรวจสอบและติดตามผู้สนใจจองห้องพักจากหน้าเว็บ
- **บันทึกมิเตอร์น้ำ-ไฟ & ใบแจ้งหนี้ (Utilities & Invoices)**: คำนวณค่าน้ำ-ค่าไฟอัตโนมัติ ออกบิล QR Code และระบบตรวจสลิป
- **ระบบแจ้งซ่อมบำรุง (Maintenance)**: ติดตามสถานะงานซ่อม แนบรูปถ่ายจุดชำรุด กำหนดช่างผู้รับผิดชอบ และระดับความเร่งด่วน
- **ระบบจัดการพัสดุไปรษณีย์ (Parcels)**: บันทึกพัสดุเข้า แจ้งเตือนห้องพัก และบันทึกการรับของ
- **กระดานข่าวสารและประกาศ (Announcements)**: แจ้งเตือนกิจกรรมและข่าวสารสำคัญภายในหอพัก
- **รายงานและสถิติ (Reports)**: สรุปอัตราการเข้าพัก รายรับประจำเดือน และแนวโน้มการใช้น้ำ-ไฟ
- **จัดการผู้ใช้งาน (Users)**: กำหนดสิทธิ์ Admin, Staff, Student รีเซ็ตรหัสผ่าน และควบคุมการเข้าถึง
- **ตั้งค่าระบบ (Settings)**: กำหนดอัตราค่าน้ำ ค่าไฟ ค่าส่วนกลาง และเบอร์พร้อมเพย์รับเงิน

## 🚀 การติดตั้งและขึ้นระบบบน GitHub Pages

1. นำไฟล์ทั้งหมดขึ้น GitHub Repository โดยคงโครงสร้างโฟลเดอร์ไว้
2. ไปที่หน้า Repository บน GitHub $\rightarrow$ เมนู **Settings**
3. เลือกแถบ **Pages** ทางซ้ายมือ
4. ในส่วน **Build and deployment** $\rightarrow$ เลือก Source: `Deploy from a branch` $\rightarrow$ Branch: `main` / `root` $\rightarrow$ กด **Save**
5. รอ 1–2 นาที เว็บไซต์จะออนไลน์และพร้อมใช้งานทันทีครับ
