# 🏢 Tanakrit Dormitory — หอพักชายธนกฤษฎ์ นครศรีธรรมราช
> **ระบบบริหารจัดการหอพักแบบ All-in-One ครบวงจร (Modern Dormitory Management System)**

ระบบเว็บไซต์ประชาสัมพันธ์และโปรแกรมบริหารจัดการหอพักชายธนกฤษฎ์ จังหวัดนครศรีธรรมราช ออกแบบด้วยธีมสี Deep Teal, Emerald, Sand, และ Mint สวยงาม ทันสมัย รองรับการใช้งานทั้งบนคอมพิวเตอร์และมือถือ ทำงานแบบ Standalone (เปิดใช้งานได้ทันทีทั้งผ่านเบราว์เซอร์ `file:///`, เว็บเซิร์ฟเวอร์ และ GitHub Pages)

---

## ✨ ฟังก์ชันและระบบภายใน

### 1. หน้าหลักสำหรับผู้สนใจเช่า (Landing Page)
- **Hero & Overview**: สรุปข้อมูลสำคัญและจุดเด่นของหอพัก
- **Room Catalog**: รูปแบบห้องพัก 3 สไตล์ (Standard Fan, Standard Air, Deluxe Corner)
- **Rate Calculator**: เครื่องคำนวณประมาณการค่าใช้จ่ายแรกเข้าแบบเรียลไทม์
- **Facilities & Location**: สิ่งอำนวยความสะดวกครบครัน และแผนที่การเดินทาง (ใกล้วิทยาลัยช่างศิลป์ นครศรีธรรมราช)

### 2. ระบบบริหารจัดการหลังบ้าน (Management Dashboard)
- **ผังห้องพัก (Interactive Floor Plan)**: แสดงสถานะห้องพัก 3 ชั้น รวม 24 ห้อง (ว่าง / มีผู้พัก / ปิดปรับปรุง)
- **ทะเบียนผู้พักอาศัย (Tenants)**: บันทึกข้อมูลสัญญา วันที่เข้าพัก และเบอร์ติดต่อ
- **บันทึกมิเตอร์น้ำ-ไฟ & ใบแจ้งหนี้ (Utilities & Invoices)**: คำนวณค่าน้ำ-ค่าไฟอัตโนมัติ พร้อมพิมพ์ใบแจ้งหนี้ และ QR Code พร้อมเพย์
- **ระบบแจ้งซ่อมบำรุง (Maintenance)**: ติดตามสถานะงานซ่อม กำหนดช่างผู้รับผิดชอบ และระดับความเร่งด่วน
- **ระบบจัดการพัสดุไปรษณีย์ (Parcels)**: บันทึกพัสดุเข้า แจ้งเตือนห้องพัก และบันทึกการรับของ
- **กระดานข่าวสารและประกาศ (Announcements)**: แจ้งเตือนกิจกรรมและข่าวสารสำคัญภายในหอพัก
- **รายงานและสถิติ (Reports)**: สรุปอัตราการเข้าพัก รายรับประจำเดือน และแนวโน้มการใช้น้ำ-ไฟ

## 🚀 การติดตั้งและขึ้นระบบบน GitHub Pages

1. นำโฟลเดอร์ขึ้น GitHub โดยคงโครงสร้าง `css/`, `js/`, และ `index.html` ไว้
2. ไปที่หน้า Repository บน GitHub $\rightarrow$ เมนู **Settings**
3. เลือกแถบ **Pages** ทางซ้ายมือ
4. ในส่วน **Build and deployment** $\rightarrow$ เลือก Source: `Deploy from a branch` $\rightarrow$ Branch: `main` / `root` $\rightarrow$ กด **Save**
5. รอ 1–2 นาที เว็บไซต์จะออนไลน์และพร้อมใช้งานทันทีครับ
